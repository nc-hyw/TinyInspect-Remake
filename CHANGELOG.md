# Changelog

All notable changes to this project will be documented in this file.

Older releases are documented in [CHANGELOG-ARCHIVE.md](CHANGELOG-ARCHIVE.md).

## [v1.5.3] 2026-10-14
- Updated compatibility for the API changes in patch 12.1.5
- Replaced removed global item APIs with C_Item APIs for item information, quality colors, and equipment checks
- Updated the compatibility announcement in English, Simplified Chinese, and Traditional Chinese

## [v1.5.2] 2026-10-14
- TOC-only update: added support for 12.1.5

## [v1.5.1] 2026-09-07
- Fixed inspect frame title characters not displaying correctly on some European clients
- Fixed socketed gems sometimes appearing as empty in the inspect panel
- Centralized user-facing text in locale files and added complete English defaults

## [v1.5.0]
- Refactored Setting Panel
- Implemented Announcement feature
- Added Font Setting
